What's new

Saetta versions

Saetta 1.4.6

  • Fast integrity verification, now included for free.
  • Over 70 integrity algorithms to choose from (BLAKE3, SHA-256, SHA-3, Whirlpool…) for verified copies and for checksum files, with Saetta Professional.
  • Even faster copies to USB sticks.
  • Redesigned Feedback page: your message goes straight from the app, with attachments and anonymized logs.
  • Fixed: Saetta appeared twice in the classic menu (Show more options), with an icon on a black background.
  • Fixed: after a move, File Explorer sometimes kept showing the files in the source folder until it was refreshed.
  • Fixed: when maximized, the Checksum and Sync windows could flicker.
  • Fixed: on some PCs the File Explorer integration switches turned themselves off when the window lost focus.
  • Various usability, reliability and security fixes.

Saetta 1.4.5

  • Questions about files that already exist now work as in Windows: replace, skip, or compare the two files and choose which to keep.
  • History: you can now pause it and delete one or more entries, and each row shows what was copied and from where to where.
  • Copy to and Move to: the destination is remembered as soon as the copy starts, and a recent folder can be removed with the X.
  • Files dragged from 7-Zip and WinRAR into File Explorer are now copied by Saetta.
  • The copy window now opens on top of the others.
  • Deleting: only the confirmation appears first, the delete window opens after you choose Yes.
  • Smoother speed graph, visible even when copying a few small files.
  • Fixed a bug where, since 1.4.2, copying folders did not use Saetta's engine and was slower.
  • Fixed a bug where copying a folder onto an identical one asked nothing and counted the files as copied.
  • Fixed a bug where Replace could fail with Access denied on read-only or hidden files.
  • Fixed a bug where Saetta could crash when a window closed with text selected, including during updates.
  • Bug fixes and stability improvements.

Saetta 1.4.4

  • Added support for the MTP protocol, to exchange files with phones and cameras.
  • Fixed a bug where Saetta could crash right after a copy started, leaving empty files.
  • Fixed a bug where dragging files out of 7-Zip, WinRAR and similar programs copied nothing.
  • Fixed a bug where cloud folders (such as OneDrive or Dropbox) were not counted and copied in full.
  • Fixed a bug where Saetta crashed with an error when an update started.
  • Linked folders (junctions and symbolic links) are now skipped instead of being copied again and again.
  • Fixed a bug where the progress percentage could show 100% while files were still left to copy.

Saetta 1.4.2

  • Saetta Professional trial: with a trial code Professional is active for 5 days, and Settings shows until when.
  • Copied folders keep their original created and modified dates, as files already did.
  • Updating from the app: a bar shows the download and the install, and if Windows does not finish the update the first time, Saetta resumes it by itself.
  • Fixed: Saetta appeared twice in the classic right-click menu (Show more options).
  • The copy window also shows the source and destination drive (for example C:\…\Photos → E:\Backup).

Saetta 1.4.1

  • Saetta now also appears in Windows 11's classic menu (Show more options), with the same items as the main menu.
  • Fixed: on Windows installed in some languages, at first launch Saetta said robocopy was damaged and would not start.

Saetta 1.4

  • New proprietary copy engine, built from scratch: it recognizes SSDs, hard disks, USB sticks and SD cards and picks the fastest way for each. Up to 25 times faster than File Explorer with many small files.
  • Copies start sooner: the engine starts while the window opens.
  • Paste and drag with Saetta: with the option on, File Explorer's Paste and dragging files go to Saetta too, not just Ctrl+V.
  • Protected folders: if a copy needs administrator permission, only Windows' own prompt appears, for that copy only. Saetta still does the copy.
  • Copy to… and Move to… are now free.
  • The speed limit is now part of Saetta Professional.
  • Opening a checksum file (.sha256, .md5, .b3 and more) shows its verification right away.
  • Updates: at startup Saetta offers the new version, with Update now, Later and Don't show again. With the File Explorer integration on, it tells you even when it is closed.
  • A refreshed Overview.
  • Replacing existing files is faster, and if you cancel, the ones not reached yet stay untouched.
  • Fixed Saetta closing unexpectedly when Windows changed its theme or colors during a copy.
  • Many reliability and security fixes.

Saetta 1.3.6

  • Fixed: after opening Settings, the speed limit could turn itself on at 10 MB/s. Anyone affected is back to full speed automatically.
  • New: when an update is available, Saetta shows it on the Overview and installs it in one click.
  • A tidier, easier-to-read Overview.
  • Copying page reorganized: Progress window, Speed, Delete, Data integrity and After each job. The "Interrupted copies at startup" option is now under Data integrity.
