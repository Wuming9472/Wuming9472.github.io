How we measured

Every program had the same conditions. If you want to repeat the tests, ask us for the scripts.

  • The same PC for all, with the same files and the same disks.
  • Before each copy the destination is emptied and Windows' memory freed, so every program really reads from the disk.
  • The time runs from the start until the data is written to the destination disk: Windows' cache is flushed before the clock stops.
  • Saetta is measured from the app, the way you use it: the copy starts as from File Explorer's menu and the time stops when the job shows in its history. Starting the app is included.
  • File Explorer is measured with Windows' own copy engine, the one it uses when you copy and paste.
  • TeraCopy and FastCopy start as from their File Explorer menu and close by themselves at the end: starting them is included, as for Saetta. No program checks the files after copying.
  • robocopy, Windows' command-line copy tool, is started from the terminal and copies on 8 threads at a time.
  • Three runs per program, in a different order each round, after a warm-up copy that does not count. The value shown is the median.
  • Deleting is permanent for everyone, without the Recycle Bin. For Saetta the time starts at the click on Yes in its confirmation window.
  • Antivirus on throughout the tests, as on an everyday PC.
  • With large files every program reaches the disk's speed: there the differences are small, and the results show it.
