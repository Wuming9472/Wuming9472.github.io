测试方法

所有程序的测试条件完全相同。如需重复测试，可以向我们索取脚本。

  • 所有程序使用同一台电脑、同样的文件和同样的磁盘。
  • 每次复制前都会清空目标位置并释放 Windows 的内存，确保每个程序都真正从磁盘读取。
  • 计时从开始一直到数据写入目标磁盘：停止计时前会清空 Windows 缓存。
  • Saetta 通过应用本身测量，与你实际使用的方式相同：复制像从文件资源管理器菜单启动一样开始，任务出现在历史记录中时停止计时。包含应用的启动时间。
  • 文件资源管理器使用 Windows 自带的复制引擎测量，与你平时复制粘贴时相同。
  • TeraCopy 和 FastCopy 以从文件资源管理器菜单启动的方式运行，结束后自动关闭：与 Saetta 一样，计时包含程序启动。所有程序在复制后都不校验文件。
  • 每个程序测试三次，每轮顺序不同，之前先进行一次不计入的预热复制。显示的数值为中位数。
  • 所有程序的删除都是永久删除，不经过回收站。Saetta 的计时从在确认窗口中点击“是”开始。
  • 测试期间杀毒软件始终开启，与日常使用的电脑相同。
  • 对于大文件，所有程序都能达到磁盘的速度：此时差异很小，结果中也如实体现。
  • TeraCopy 和 FastCopy 是其各自所有者的商标。
