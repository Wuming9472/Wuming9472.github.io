Saetta 版本

Saetta 1.4.6

  • 新增免费的快速完整性校验。
  • 70 多种完整性算法可选（BLAKE3、SHA-256、SHA-3、Whirlpool 等），用于校验副本和校验和文件，需 Saetta Professional。
  • 复制到 U 盘的速度更快。
  • 全新改版的反馈页面：消息直接从应用发出，可附加文件和匿名化的日志。
  • 已修复：Saetta 在经典菜单（显示更多选项）中出现两次，且图标带有黑色背景。
  • 已修复：移动文件后，文件资源管理器有时仍在源文件夹中显示这些文件，直到刷新为止。
  • 已修复：窗口最大化时，“校验和”和“同步”窗口可能会闪烁。
  • 已修复：在部分电脑上，窗口失去焦点时，文件资源管理器集成开关会自行关闭。
  • 多项易用性、可靠性和安全性修复。

Saetta 1.4.5

  • 目标位置已有同名文件时，现在与 Windows 一样：替换、跳过，或比较两个文件后选择保留哪一个。
  • 历史记录：现在可以暂停记录，删除一条或多条记录，每一行都会显示复制了什么以及从哪里到哪里。
  • “复制到…”和“移动到…”：复制一开始就会记住目标位置，最近使用的文件夹可以用 X 移除。
  • 从 7-Zip 和 WinRAR 拖到文件资源管理器的文件，现在由 Saetta 复制。
  • 复制窗口打开时现在会显示在最前面。
  • 删除：先只显示确认，选择“是”之后才打开删除窗口。
  • 速度图表更流畅，复制少量小文件时也能看到。
  • 修复了自 1.4.2 起复制文件夹时没有使用 Saetta 引擎、速度变慢的问题。
  • 修复了把文件夹复制到完全相同的文件夹上时不询问、并把文件算作已复制的问题。
  • 修复了“替换”在只读或隐藏文件上可能提示“拒绝访问”的问题。
  • 修复了窗口在有选中文本时关闭（包括更新期间）可能导致 Saetta 崩溃的问题。
  • 错误修复和稳定性改进。

Saetta 1.4.4

  • 新增 MTP 协议支持，可与手机和相机交换文件。
  • 修复了 Saetta 可能在复制开始后立即崩溃并留下空文件的问题。
  • 修复了从 7-Zip、WinRAR 等程序中拖出文件时没有任何文件被复制的问题。
  • 修复了云文件夹（如 OneDrive 或 Dropbox）未被完整计数和复制的问题。
  • 修复了 Saetta 在开始更新时出错崩溃的问题。
  • 链接的文件夹（联接点和符号链接）现在会被跳过，而不会被重复复制。
  • 修复了仍有文件待复制时进度百分比可能显示 100% 的问题。

Saetta 1.4.2

  • Saetta Professional 试用：使用试用码后，Professional 可使用 5 天，设置中会显示截止日期。
  • 复制的文件夹会保留原始的创建和修改日期，与文件一样。
  • 在应用内更新：进度条显示下载和安装进度；如果 Windows 第一次未完成更新，Saetta 会自动继续。
  • 修复：Saetta 在经典右键菜单（显示更多选项）中出现两次。
  • 复制窗口还会显示源驱动器和目标驱动器（例如 C:\…\照片 → E:\备份）。

Saetta 1.4.1

  • Saetta 现在也会出现在 Windows 11 的经典菜单（显示更多选项）中，菜单项与主菜单相同。
  • 修复：在某些语言的 Windows 上，Saetta 首次启动时提示 robocopy 已损坏并且无法启动。

Saetta 1.4

  • 全新的专有复制引擎，从零开发：可识别 SSD、机械硬盘、U 盘和 SD 卡，并为每种设备选择最快的方式。处理大量小文件时，速度最高可达文件资源管理器的 25 倍。
  • 复制更快开始：窗口打开的同时引擎即已启动。
  • 使用 Saetta 粘贴和拖放：开启该选项后，文件资源管理器中的粘贴和拖放文件也交由 Saetta 处理，不只是 Ctrl+V。
  • 受保护的文件夹：如果某次复制需要管理员权限，只会出现 Windows 自身的提示，且仅针对这一次复制。复制仍由 Saetta 完成。
  • "复制到…"和"移动到…"现已免费。
  • 速度限制现在属于 Saetta Professional。
  • 打开校验和文件（.sha256、.md5、.b3 等）时，Saetta 会立即显示校验。
  • 更新：启动时 Saetta 会提示新版本，可选择"立即更新"、"稍后"或"不再显示"。开启文件资源管理器集成后，即使 Saetta 已关闭也会提醒。
  • 全新的概览页面。
  • 替换已有文件更快；如果取消，尚未处理的文件保持不变。
  • 修复了复制过程中 Windows 更改主题或颜色时 Saetta 意外关闭的问题。
  • 大量可靠性和安全性修复。

Saetta 1.3.6

  • 修复：打开设置后，速度限制可能会自行开启为 10 MB/s。受影响的用户将自动恢复全速。
  • 新增：有可用更新时，Saetta 会在概览中提示，并可一键安装。
  • 概览页面更整洁、更易读。
  • 复制页面重新整理：进度窗口、速度、删除、数据完整性和任务结束后。“开机时检查中断的复制”选项现在位于数据完整性中。
